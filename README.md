# 📊 OkCupid--Analysis--Dashboard
OkCupid Analysis and interactive dashboard using Microsoft Excel

# 📌 Project Overview

The OkCupid Data Analysis Dashboard is an Excel-based data analytics project that focuses on analyzing user profile data from the OkCupid online dating platform.

The project involves exploring user demographics, relationship status, lifestyle preferences, income distribution, and age groups to identify meaningful patterns and trends.

Using Microsoft Excel, raw data was cleaned, transformed, and analyzed through Pivot Tables to generate meaningful insights. The project aims to demonstrate practical data analysis skills and the ability to convert raw data into useful information.

# 🔄 Project Workflow

1. 🧹 Data Cleaning
 - Selected 24 relevant columns for analysis.
 - Standardized gender values from 'm' and 'f' into 'male' and 'female'.
 - Created age-group categories.
 - Extracted date and month information from the Last Online column.
 - Prepared the selected dataset for analysis.

2. 🔍 Data Analysis
 - Used Excel Pivot Tables to summarize and analyze user information.
 - Performed gender distribution analysis.
 - Analyzed relationship status across genders.
 - Explored smoking and drinking habits.
 - Examined income distribution.
 - Analyzed user distribution across different age groups.

3. 📈 Data Collection
 - Imported the original OkCupid dataset containing approximately 59,947 user records and 144 columns.
 - Reviewed the available user profile attributes.


4. 📊 Dashboard development
 - Organized analytical results for dashboard reporting.
 - Prepared the workbook with a separate Dashboard sheet for presenting insights.

# 🎯 Project Objectives
The main objective of this project is to analyze OkCupid user profile data and identify meaningful patterns and trends in user demographics, relationship status, lifestyle preferences, income distribution, and age groups. The project aims to clean and transform raw data, perform data analysis using Microsoft Excel and Pivot Tables, compare different user categories, and generate valuable insights from the dataset. It also focuses on presenting the analyzed information in an organized dashboard to make the results easier to understand and interpret.
